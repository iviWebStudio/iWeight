## Этап: 1–6 готовы в коде (ядро, схема, API, агент, web); дальше — Android

### Сделано
- Монорепо: pnpm workspaces + Turborepo, TypeScript 5.9.3, Prettier. Корень: `package.json`,
  `pnpm-workspace.yaml`, `turbo.json`, `tsconfig.base.json`, `.gitignore` (`.env` исключён).
- `packages/core` — детерминированное расчётное ядро, **готово**:
  - `dates.ts` — календарные даты `YYYY-MM-DD`, арифметика по epoch-дням (DST-безопасно),
    дата инстанта в IANA-поясе.
  - `units.ts` — вес хранится в целых граммах; конверсия kg/lb; диапазон 20–400 кг.
  - `analytics.ts` — дневной ряд (утреннее = самое раннее измерение дня), средние за 7/30
    календарных дней с количеством измерений (пропуски не заполняются), OLS-тренд, прогресс цели
    отдельно для снижения/набора/поддержания, анализ темпа (14 vs предыдущие 14 дней), прогноз с
    80 % интервалом (t-распределение) и статусами `insufficient_data / no_trend / moving_away /
    too_far / achieved / ok`, сводка `computeSummary`. Пороги — в `ANALYTICS_RULES`.
- `supabase/migrations/20261023000001_init.sql` — схема (9 таблиц из ТЗ), ограничения, индексы,
  column-level GRANT, RLS `user_id = auth.uid()` на всех пользовательских таблицах, триггер
  создания профиля, `delete_current_user()`, `conversations.pending_action` для подтверждения
  удалений через чат.
- `db/local/00_supabase_shim.sql` + `10_local_grants.sql` + `scripts/db-local-setup.sh` —
  локальный Postgres 16 без Docker, эмулирующий `auth.uid()`/роли Supabase.
- `apps/demo` — автономное интерактивное демо (один HTML): вход, онбординг, главная панель
  (последний вес, цель, прогноз с 80 % интервалом, средние 7/30, темп, график с прогнозом),
  ввод, история с правкой/удалением, чат-агент (локальный сценарий с метками инструментов,
  подтверждение удаления), настройки профиля/цели/памяти агента, удаление аккаунта. Расчёты —
  настоящее `packages/core`; данные — `localStorage`.
- `packages/contracts` — Zod-схемы всех запросов/ответов, формат ошибок, клиент `createApiClient`.
- `apps/api` — Fastify 5: все endpoint-ы ТЗ §9 + health/ready, цели, память, диалоги, удаление
  аккаунта (`docs/API_SPEC.md`). Каждый запрос — транзакция под ролью `authenticated` с
  `auth.uid()` = `sub` токена (RLS). Аутентификация Supabase (JWKS) или локальная (dev/CI).
  Rate-limit, лимит тела, helmet, CORS, логи без токенов/весов/сообщений.
- GPT-агент (`apps/api/src/agent`, `docs/AI_AGENT.md`): Responses API, инструкция v1, 10
  инструментов, ADR-009/012/013/014, память, резюме диалогов, `agent_runs` с токенами и стоимостью.

- `apps/web` — Next.js 16 (App Router, все страницы клиентские, статическая сборка): вход и
  регистрация, онбординг, главная, запись, история, чат, настройки, удаление аккаунта; клиент
  `createApiClient`; вход Supabase или локальный (ADR-015). Тестовый API-сервер для e2e с
  детерминированной заменой модели — `apps/api/src/test/e2e-server.ts` (в сборку не входит).
